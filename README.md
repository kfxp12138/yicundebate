# 一寸欢喜辩论赛控场台

辩题：高度不确定的时代里，我们还该 / 不该教育孩子“努力会有回报”。

黑色主题、白色圆盘倒计时，支持 30 秒提醒、到时响铃、双方独立计时和实时观众投票。

## 操作

- 质询环节点击“质询方计时”开始或继续；接质方回答时，主持人点击“接质回答 · 暂停”。系统不会自动识别发言人。
- 二辩对辩和自由辩论默认从正方开始，可在开始前切换发言方；进行中点击“切换发言方”交替扣除各自时间。圆盘始终显示当前发言方的剩余时间，下方同时显示双方余额。
- 时间到或点击“结束发言”后，可以进入下一环节。“重置”恢复当前环节的完整时间，“全场重置”回到第一环节并清除本地投票记录，不清除服务器票数。
- 保留原有初始投票、各环节记录和净跑票结果统计。

```bash
npm start
npm test
```
